# Graveknit

A necromancy idle game for the browser. Stitch undead Abominations out of the parts of what you kill, reroll them toward perfect stats, and push deeper into the crypt.

**Play it:** https://tysal21.github.io/graveknit/ (after the first publish)

## Running it on your computer

1. Install [Node.js](https://nodejs.org) (the LTS version).
2. In this folder, run `npm install` once.
3. Run `npm run dev` and open the link it prints (usually http://localhost:5173).

Run `npm test` to check that the game's rules still work after a change.

See `CLAUDE.md` for how the code is organised and the design decisions it follows.
